راجع التغييرات الحالية غير المُدمَجة في هذا المستودع مراجعة مستقلة قبل اعتبارها جاهزة.

النطاق المطلوب: $ARGUMENTS
(إن كان فارغًا فراجع كل التغييرات غير المُدمَجة. وإن حُدّد مسار أو ملف فاقتصر على ذلك النطاق.)

حقائق ملتقطة للسياق:
- حالة الشجرة: !`git status --short`
- حجم الفرق: !`git diff --stat`
- آخر 3 commits: !`git log --oneline -3`

المطلوب:
1. اقرأ الفرق الفعلي بنفسك قبل أي حكم: `git diff` للملفات المتعقّبة، واقرأ الملفات الجديدة غير المتتبَّعة كاملة.
2. راجع: الصحة الوظيفية ومطابقة المطلوب، الثغرات الأمنية، التزامن وسلامة المعاملات، سلامة قاعدة البيانات والترحيلات، تغطية الاختبارات ومعايير القبول، الآثار الجانبية والوثائق.
3. لكل عيب: الملف والسطر، الوصف، الدليل (مقتطف كود أو أمر أو اختبار)، وشدّته (حرج / عالٍ / متوسط / منخفض).
4. ميّز صراحةً بين ما تحقّقت منه وما لم تستطع التحقق منه.

قيود إلزامية:
- قراءة فقط: لا تعدّل أي ملف، ولا تنفّذ `git add` أو `commit` أو `push`، ولا أي عملية تغيّر حالة المستودع أو قاعدة البيانات.
- لا تعتمد على الخلاصة أعلاه بديلًا عن قراءة الفرق بنفسك: الخلاصة سياق لا دليل.
