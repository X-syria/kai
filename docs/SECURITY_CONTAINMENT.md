# KAI — سجل الاحتواء الأمني

## 2026-11-05

نُفذت إجراءات احتواء محلية بعد اكتشاف أسرار في ملف البيئة وكائنات Git غير قابلة للوصول.

- ضُبطت صلاحيات `.env` إلى `0600`، ولم تُطبع أي قيمة.
- يحتوي `.env` المحلي على ثمانية مفاتيح مُعبأة، منها مفتاح نموذج، وبيانات OAuth، وسر تشفير Google. هذا الملف غير صالح للتسليم ويجب تدوير القيم الخارجية قبل أي استخدام حقيقي.
- كائنان Git غير قابلين للوصول كانا يحتويان مؤشرات `CLIENT_SECRET` و`ENCRYPTION_SECRET`. تم فحصهما دون إخراج القيم، ثم تنفيذ `reflog expire` و`git gc --prune=now`، وأصبحا غير قابلين للقراءة من مخزن Git المحلي.
- فحص الملفات المتتبعة لم يجد قيماً من أنماط مفاتيح Google/Private Key؛ وجود نص اختبار `PRIVATE KEY` في اختبار الترحيل ليس credential.

## ما لم يُنفذ

تدوير مفاتيح Planner وGoogle OAuth وسر تشفير Google لم يُنفذ من هذه البيئة لعدم وجود وصول موثق إلى لوحات/موصلات الخدمات. يجب اعتبار القيم مكشوفة، وإبطالها وإصدار بدائلها قبل ربط KAI بخدمة حية. لا يُعاد فتح Google linking بمجرد تبديل قيمة بيئية؛ الوضع الحالي مغلق عمداً ويحتاج مراجعة identity-confirmation.

## معيار الإغلاق

يُغلق هذا الإجراء بعد إثبات تدوير القيم خارجياً، وإبطال refresh tokens المتأثرة، وتحديث secret manager/CI protected variables، ثم تشغيل فحص تاريخ Git في نسخة clean وعدم وجود أسرار في refs أو artifacts.
